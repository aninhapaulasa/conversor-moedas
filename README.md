# 💱 Conversor de Moedas

Aplicação web desenvolvida com HTML, CSS e JavaScript que permite converter valores entre diferentes moedas utilizando taxas de câmbio obtidas de uma API.

## 🚀 Funcionalidades

- Conversão entre Real (BRL), Dólar (USD) e Euro (EUR).
- Consulta de taxas de câmbio por meio da API Frankfurter.
- Inversão das moedas de origem e destino.
- Validação dos valores informados.
- Formatação monetária com `Intl.NumberFormat`.
- Tratamento de erros de requisição.
- Interface responsiva para dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API REST
- Fetch API
- Async/Await

## 🌐 API utilizada

[Frankfurter API](https://www.frankfurter.app/)

A API disponibiliza taxas de câmbio de referência para diferentes moedas.

## 💻 Como executar

1. Clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando o Live Server.
4. Informe um valor, selecione as moedas e clique em **Converter**.

É necessária uma conexão com a internet para consultar as taxas de câmbio.
